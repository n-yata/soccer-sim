# 実装後の振り返り

## 作業概要

マッチアップ解説（優位ポイント・総合優劣判定）を、組み合わせごとの手書きデータから、
フォーメーションの**特徴タグ × 噛み合わせルール**による導出へ置き換えた。
組み合わせ数が n(n-1)/2 で増えるため手書きではコンテンツ拡張（フォーメーション追加）が
破綻することへの対処であり、執筆の単位を「組み合わせ」から「ルール」へ移した。
公開API（`matchups` / `getMatchup`）と画面（`.vue`）は変更していない。

## 学んだこと

**技術的な学び**:

- **既存の手書きコンテンツは「消す対象」ではなく「ルールの仕様書」だった**。
  着手前の調査で、用語集18件のうち9件が削除対象の手書き文にしか存在しないことが判明した。
  単に消していれば `soccerTerms.test.ts` が落ちるだけでなく、用語のインライン表示（FR-11）と
  用語集（FR-10）が中身を失っていた。**置き換える前に「何がそのデータにしか無いか」を
  洗い出す**必要がある
- **重複発火には2つの経路がある**。(1) 条件の包含（機械的に検出できる）、
  (2) **タグの共起**（条件は独立でも実データ上つねに同じフォーメーションが両方のタグを持つ）。
  後者はルール単体の定義を見ても分からず、包含検知テストでも捕まらない。
  今回は 4-4-2 が `中盤フラット4枚` と `ライン間が空く` を常に併せ持つことで発生していた
- **「テストが全部緑」は「正しい」を意味しない**。第1回レビューの指摘で、校正アンカー
  `4-4-2 vs 3-5-2` が diff = -2 とちょうど閾値で、**二重計上ごと帳尻が合っていた**ことが判明。
  アンカーが通っていること自体が正しさの証明にならない場合がある
- **欠陥を塞ぐ修正が、同型の欠陥を新たに作りうる**。テーマ間引きの導入により旧 R17 が
  一度も出力されなくなり、「ライン間」の語が生成文言から消えた。しかも
  `soccerTerms.test.ts` は `radarAxes` の説明文で偶然その語を拾えていたため緑のまま。
  **塞いだつもりの穴と同じ型の穴を、塞ぐ手段そのものが開けていた**
- **「静かに落とす」仕組みには、落ちたことを検知する手段を必ず添える**。テーマ間引きは
  ルールを黙って捨てる仕組みなので、採用されないルールを検知するテストを対で用意した

**プロセス上の改善点**:

- **サブエージェントの報告を実行で検証する価値**が大きかった。実装報告・レビュー指摘とも
  一部が事実と異なっていた（レビューが提案した修正案は新たな共起重複を生むものであり、
  「1回生成へ単純化」の提案は実行するとテストが落ちる）。
  **提案をそのまま適用せず、自分で計算・実行して確かめる**ことで2件の誤りを回避できた
- **追加したテストが空振りでないことを実測で確認した**。テーマ間引きを一時的に外すと2件が
  赤くなり、許容リストを空にすると到達不能検知が赤くなることを確認している。
  「テストを足した」だけでは、それが機能しているかは分からない
- 校正アンカー（手書き時代の判定6件）を設計段階で決めておいたのが有効だった。
  ルール表という自由度の高いものを扱うとき、**外部基準が無いと際限なく調整できてしまう**

## 次回への改善提案

- **A-2（フォーメーション追加）では、生成後の文言で用語集18件が維持されるかを必ず確認する。**
  ルール表段階の用語検査（`matchupRules.test.ts`）は、テーマ間引きで死んだルールの文言でも
  緑になる。今回まさにそれで1件見落とした
- **判定が意図と合わないとき、閾値を動かさない。** 原因はルール表の左右非対称であり、
  閾値で辻褄を合わせるとフォーメーション追加時に全組の判定が崩れる。
  同様に、**件数を揃えるためだけにルールを足さない**（見た目への過学習になる）
- テーマ `前線と守備的MFの噛み合わせ` は攻守のルールが同居しており、現行データで同一サイドに
  同時成立しないのは偶然。`2トップ` と `守備的MF2枚` を併せ持つ形（4-2-2-2 等）を追加すると
  片方が落ちる。到達不能検知テストが赤くなるので気づけるが、追加時は留意すること
- **上書き機構は今回作らなかった**（「全件を生成に統一」の判断による）。特定の組み合わせで
  生成文の質が不足する場合、`matchups.ts` に overrides をマージする層を足せば他を変えずに
  導入できる。現時点では必要と判断していない
- 4-4-2 vs 3-5-2 の 4-4-2 側が優位ポイント1件と薄い。判定（3-5-2 有利）とは整合するが、
  画面上のバランスとしては再考の余地がある。A-2 でルールが増えれば自然に解消する可能性もある
