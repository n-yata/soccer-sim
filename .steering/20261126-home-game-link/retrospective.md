## 学んだこと

**技術的な学び**:
- Vitest は `vite.config.ts` の `base` を `BASE_URL` に反映しない（`/` になる）。`import.meta.env.BASE_URL` を使う表示は、
  `vi.stubEnv("BASE_URL", ...)` で公開時の値にして確かめる
- Vue Router の外のページ（同じサイトの別アプリ）へは `router-link` ではなく、`BASE_URL` から組み立てた `<a>` で遷移する

**プロセス上の改善点**:
- 前の PR で「次の PR に回す」と書いた一文（導線はまだ無い）を、次の PR で忘れずに更新できた。スコープ外にした項目は、
  後で消す文言として振り返りに残しておくと拾いやすい
