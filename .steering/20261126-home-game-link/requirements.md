# 要求内容

## 概要

フォーメーションラボのホーム（フォーメーション一覧画面）から、ブラウザ版の戦術ゲーム（`/soccer-sim/game/index.html`）へ遷移するリンクを置く。

## 背景

シャビの要望「ラボのホームからゲームへのリンクを追加して」（2026-11-26）。ゲームは PR #20 で `/game/` に公開したが、
ラボの画面からの導線が無く、URL を知っている人しか遊べない（`.steering/20261126-game-pwa/` でスコープ外とした続き）。

## 実装対象の機能

### 1. ゲームへのリンク
- ホームのページヘッダー（Jリーグの外部リンクと同じ場所）に「戦術ゲームで遊ぶ」を置く
- 同じサイト内のページなので同じタブで開く。ゲームは Vue Router の外（別アプリ）なので、通常の `<a>` で遷移する
- URL は `BASE_URL` ＋ `game/index.html`。Godot の Service Worker は `index.html` の名前でキャッシュするため、
  `/game/` ではなく `index.html` まで含める（オフライン起動のため）
- 環境変数での出し分けはしない（同じサイトに必ずある）

## 受け入れ条件

- [ ] ホームのヘッダー内に「戦術ゲームで遊ぶ」リンクがあり、`href` が `${BASE_URL}game/index.html`
- [ ] 同じタブで開く（`target` を持たない）
- [ ] Jリーグのリンクが無効（未設定）でも表示される
- [ ] ワイヤーフレーム（`wireframe-formation-list`）・画面設計・コンポーネント設計・機能概要の画面一覧・単体テスト仕様を同じ PR で更新する

## スコープ外

- 他の画面・主ナビ（`AppHeader`）への追加（主ナビは6項目で横幅の余裕が無い）
- ゲームからラボへ戻る導線（ゲーム側の変更）
