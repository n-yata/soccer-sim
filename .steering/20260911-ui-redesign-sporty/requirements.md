# 要求内容

## 概要

既存機能（フォーメーション一覧・比較）はロジック完成済みだがデザインに未着手だったため、
「スポーティ&エネルギッシュ」路線でUIを刷新する。ロジック・機能は変更せず、見た目のみ改修する。

## 背景

- 機能は充実してきたが、デザインには全く手を付けていない状態だった。
- `docs/specs/2_basic-design/wireframes.drawio` に刷新後イメージ（`wireframe-formation-list-v2(刷新後)` /
  `wireframe-comparison-v2(刷新後)` ページ）を作成し、シャビの承認を得た。これを実装に反映する。

## 実装対象の機能

### 1. フォーメーション一覧画面（`FormationListPage.vue` / `FormationCard.vue`）
- グリーングラデーションのヘッダー（⚽アイコン付きタイトル、サブタイトル）
- カードを白背景＋角丸＋影のスポーティなスタイルに刷新
- 選択中カードをオレンジ（#FF6B35）で強調し、チェックマーク表示を追加
- 拡張候補カード（無効表示）の見た目を維持しつつトーンを調整
- フッターの注記をピル型バッジに変更

### 2. 比較画面（`ComparisonPage.vue` / `MatchupPitchDiagram.vue`）
- 戻るボタンをピル型・影付きに変更
- 凡例をカラーチップ（ピル型バッジ）に変更
- 総合判定エリアをチームカラーのグラデーションカード＋絵文字装飾に変更
- ピッチ図を芝生グラデーション＋ストライプ＋白線（外枠・センターライン・センターサークル・
  ペナルティエリア）を持つリアル寄りの表現に変更
- 選手アイコンを鮮やかな配色（青 #2563EB / 赤 #EF4444）＋影付きに変更
- 優位ポイントのカードをチームカラーの枠線付きカードに変更

## 受け入れ条件

### フォーメーション一覧画面
- [ ] ヘッダーがグリーングラデーションで表示される
- [ ] カードが白背景・角丸・影のスタイルで表示される
- [ ] 選択中カードがオレンジで強調表示される
- [ ] 既存の選択・自動遷移ロジックに変更がない（振る舞いは不変）

### 比較画面
- [ ] ピッチ図が芝生グラデーション＋ストライプ＋白線で表示される
- [ ] 選手アイコンが鮮やかな配色＋影付きで表示される
- [ ] 総合判定・優位ポイントがチームカラーで装飾される
- [ ] 既存の表示ロジック（`overallEdge`/`overallReason`/`advantagesForA/B`等）に変更がない

### 品質
- [ ] 既存のユニットテストがすべて通る（ロジック変更していないため）
- [ ] 型チェック・リント・ビルドが通る

## 成功指標

- ワイヤーフレーム（v2ページ）のトンマナ・配色・演出が実装に反映されている
- 既存の自動テスト（振る舞い検証）に影響を与えない

## スコープ外

- コンポーネント構成・状態管理・ルーティングなどロジック面の変更
- `functional-overview.md`「表示仕様」の記述変更（青/赤の区分自体は変わらないため対象外）
- アニメーション・トランジション等のインタラクション追加（今回は静的スタイルの刷新のみ）
