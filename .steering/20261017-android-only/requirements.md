# 要求: MVP の配布先を Android に絞る

## 背景
デザイン案（スタジアム中継風）で、縦長のピッチを画面いっぱいに見せる方向が決まった。シャビから
「PC だと違和感が出る。スマホだけをターゲットにしたほうがいいか」と相談があり、検討した。

## 決定（2026-10-17 シャビ）
- MVP の配布先は Android（Google Play・スマートフォン縦向き）だけにする
- Windows 版（Steam）は後続マイルストーン（要件定義書 §6.2。想定優先度 P1）へ移す
- 理由: 主な対象（育成年代の選手）は Android のスマートフォンで遊ぶ。縦長のピッチを主役にしたデザインの質を優先し、
  横長の配置・マウス操作・Steam への登録の作業を MVP から外す。Godot は同じコードから後で Windows へ書き出せる

## 変更する文書
- `1_requirements/`: 要件定義書（対象範囲・コンセプト・KPI・ペルソナ・§6・§7・§7.1）、非機能要件（前提の基準環境・NFR-02・10・12・19・23・25・対応 OS）、
  アーキテクチャ概要、リポジトリ構造、用語集、機能概要（表示仕様のピッチの向き）
- `2_basic-design/`: 画面設計（画面の向き）、ワイヤーフレーム（S-03 の横長の図）
- 作業中の詳細設計（`3_detail-design/`）は、この決定に合わせて直したうえで、詳細設計の作業としてコミットする
