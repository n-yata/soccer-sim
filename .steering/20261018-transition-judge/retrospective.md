- **変異の確認で、テストが1件も走っていない回が2回あった**。
  - 原因: Windows の Python から呼んだ `bash` が Git Bash ではなく、Godot が見つからなかった。

- **構文エラーになる変異を、無効として扱った**。return を消す変異は構文エラーになり、テストが走らなかった。これを「検出」と数えず、結果の種類を変える変異に差し替えた。
- **落ちたテストの名前を出すようにした**。変異の結果に、落ちたテストの名前を出す形にして、狙ったテストで落ちていることを確かめた。

## 学び
- **変異の確認は、テストが走ったことを結果ごとに確かめる**。終了コード1は「テストが落ちた」とは限らず、「テストが走らなかった」でも1になる。件数の行が無い結果は無効と表示する仕組みを、スクリプトに最初から入れておく。今回は2回目でこれが効いた。
- **左右対称な場面のテストは、鏡写しの誤りを見逃す**。即時奪回のテストは、最初はボールがすべて中央のレーン（`D-C`）だった。左右が対称なので、レーンの鏡写しを誤っても同じ結果になる。盤の端（`D-L2`）に、鏡写しを誤ったときだけ数えに入る選手を置いたテストを足すと、その変異を検出できるのはこのテストだけだった。
- **後の作業に回せる指摘でも、テスト1本で済むなら今やる**。カウンターの運ぶ先と飛び出し後の配置のつながりは、アルゴリズム7の範囲として申し送れた。けれど、今なら JE-07 の配置がそろっていて、テスト1本で固定できた。
