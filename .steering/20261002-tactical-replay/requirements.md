# 要求内容

## 概要
比較画面に、選手とボールの動きを見ながら戦術を学べる解説付き場面再生を追加する。初回はサイドの2対1を完成させる。

## 背景
静止した陣形と文章だけでは、誰の動きによって空間が生まれ、いつ優位が消えるのかを理解しにくい。ユーザーとの合意は、教材として用意した場面を自分のペースで観察する体験である。

## 実装対象の機能
### 1. サイドの2対1
- ボール保持者が守備者を引きつけ、外側を走る味方にパスする動きを表示する。
- 初期配置、引きつけ、パス、守備のカバー、戻してやり直す局面を解説する。
- 人数の優位に加え、パスのタイミングと空間を示す。カバーが間に合うと突破の条件が変わることも扱う。
### 2. 学習用の再生操作
- 要所で自動停止。再生・一時停止、前の解説、次の解説、最初からを提供する。
- 比較画面の優位ポイント付近から開ける。選択した陣形と独立した共通の戦術例であることを表示する。
- 動きを減らす設定では静止状態を段階的に表示する。

## 受け入れ条件
- [x] 選手とボールが連続的に動き、各解説ポイントで停止する。
- [x] 各停止状態の図と文章が一致し、空間・走る道・パスを形と文字でも識別できる。
- [x] 一時停止と再開、前後の解説、最初から、最後の停止が機能する。
- [x] カバーによって2対1の優位が変化する場面まで学べる。
- [x] 画面離脱・教材を閉じる・非表示タブで再生処理が停止する。
- [x] キーボードと幅375pxで操作でき、操作領域44px以上。動きを減らす設定でも同じ内容を読める。
- [x] 既存の比較・配置変更・試合シミュレーションの動作を保持する。

## 成功指標
どの選手が守備者を引きつけ、どこに空間が生まれ、カバー後にどう判断が変わるかを、図と解説を往復せず確認できる。

## スコープ外
中盤の人数優位、守備ラインの背後、実試合動画、リアルタイムAI、教材編集、選んだ陣形からの自動生成、学習履歴の永続化。
