# コミット前レビューレポート

## 第1回（2026-09-08）

- 対象: main からの未コミット差分。当初の実装は `PitchDiagram` の `flip` propsを
  上下反転から左右反転に変更するもの（`playerCy`を`100-y`固定、`playerCx`で`flip`時`100-x`）
- 結果: Critical 1件 / High 2件

### 指摘要旨

- **[Critical]** `formations.ts`の全4フォーメーションは左右対称データであり、左右反転
  （`100 - x`）は数学的に恒等変換に等しく無効。さらに上下反転をやめたことで、GK・CB等の
  中央〜対称位置の選手が完全に同一座標へ描画されるケースが以前より増加していた。
- **[High]** ラベルの左右反転により、左右の意味が実際の配置と矛盾する。
- **[High]** ドキュメントが実装できていない効果（左右非対称な配置の違いを見せる）を
  断定的に記述していた。

### 対応

シャビへ状況を報告したところ「重ね合わせはしろよ。それで左右に並べろ」という指摘があり、
反転軸の変更ではなく「2枚目の選手全体を左右にオフセットして重ねる」ことを求めていたと
判明した。`flip`を廃止し、`offsetX`（選手のx座標に加算する平行移動量、既定値0）を
新設する方針に転換した（`ComparisonPage.vue`の2枚目に`offsetX=6`を指定）。
