# 要求内容

## 概要・背景
比較と学習の入口が混在しているため、主ナビの「戦術を学ぶ」と専用陣形一覧を追加する。

## 対象・受け入れ条件
- [ ] 主ナビから学習一覧へ進み、全8陣形の教材を選べる。
- [ ] 比較一覧は2陣形の選択に集中し、学習リンクを各カードに置かない。
- [ ] 教材から学習一覧へ戻り、現在地とモバイルメニューが正しく動作する。
- [ ] 比較の不要操作撤去と独立ボードの操作・保存を両立する。
- [ ] 設定済みJリーグリンクをプレビューでも維持する。

## スコープ外
教材追加、採点・履歴、別チャットのボード拡張、既存PRのマージ。
