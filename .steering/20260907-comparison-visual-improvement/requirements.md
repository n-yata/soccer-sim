# 要求内容

## 概要

比較画面のわかりにくさを改善する。ピッチ図を重ね合わせ表示にし、解説文を「優位ポイント」の
箇条書きへ構造化・内容刷新する。

## 背景

MVPをシャビに見せたところ、「解説文もつまらないし、比較の配置もダメすぎ」という具体的な
フィードバックを受けた。ヒアリングの結果、以下の2点が原因と判明:

1. 解説文: 内容も文体も弱い（淡々とした3行の説明文だけで、どこがどう有利かが読み取りにくい）
2. 比較画面の配置: 2つのピッチ図を単純に左右へ離して並べているだけで、噛み合わせが直感的に
   伝わらない

## 実装対象の機能

### 1. ピッチ図の重ね合わせ表示

- `PitchDiagram`に`showField`（ピッチ背景の描画有無）propsを追加する。
- 比較画面では、同一エリアに`PitchDiagram`を2枚重ねて表示する（1枚目は背景あり、2枚目は
  背景なしで選手のみ）。青（フォーメーションA）・赤（フォーメーションB）の色分けはそのまま活かす。
- どのエリアで選手が重なっている（＝数的優位・不利が生まれている）かが視覚的に伝わる状態を
  目指す。

### 2. 解説文の構造化・内容刷新

- `Matchup`のデータ構造を`commentary: string`から`advantagesForA: string[]` /
  `advantagesForB: string[]`（各フォーメーションの優位ポイントの箇条書き）に変更する。
- 比較画面では、フォーメーションA・Bそれぞれの優位ポイントを見出し付き箇条書きで表示する。
- 全6組み合わせ（4-4-2, 4-3-3, 4-2-3-1, 3-5-2の総当たり）のコンテンツを、具体的な戦術用語
  （「中盤の数的優位」「サイドバック裏のスペース」等）を使って書き直す。

## 受け入れ条件

### ピッチ図重ね合わせ
- [x] 比較画面で、2つのフォーメーションのピッチ図が1つのエリアに重ねて表示される
- [x] 青（フォーメーションA）・赤（フォーメーションB）の選手が色で区別できる
- [x] `PitchDiagram`は`showField=true`（既定値）で単体表示したときも従来どおり動作する
      （後方互換）

### 解説文構造化
- [x] 各フォーメーションの優位ポイントが見出し付き箇条書きで表示される
- [x] 全6組み合わせに具体的な戦術ポイントが記載されている（一般論だけの1〜2文で終わらない）

## 成功指標

定量指標は設けない。シャビ本人が実際の画面を見て「配置が直感的」「解説が読んで面白い・
分かりやすい」と感じられることを目安とする。

## スコープ外

- アニメーション演出は今回も含めない（まずは静的な改善に集中する）
- 選手個々の詳細な役割説明（背番号・実名選手の起用等）は含めない
