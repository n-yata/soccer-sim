# 要求内容

## 概要・背景
比較を陣形の理解に集中させるため、シャビの指示に従い自由配置と試合シミュレーションを撤去する。

## 実装対象
自由配置・配置保存・試合結果・ハーフタイム采配と、それら専用の選手個体差設定を撤去する。陣形の固定配置、特性、優位の説明、切替、学習進捗、解説付き場面教材を維持する。

## 受け入れ条件
- [x] 比較画面に自由配置・試合シミュレーション・采配・選手設定が表示されない。
- [x] 保存済みの配置があっても固定配置・特性・解説で比較できる。
- [x] A/B切替・入替・不正ID案内・学習進捗が動作する。
- [x] 陣形別の場面教材が引き続き動作する。

## 成功指標
比較画面から不要な操作と専用コードの参照をなくす。

## スコープ外
保存済みlocalStorageの削除、陣形教材の変更、前回PRのマージ。
