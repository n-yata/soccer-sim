# 要求内容

## 概要

フォーメーションラボの「学習体験」を強化する3点を実装する。①一覧画面のカードに選手配置の
ミニピッチ図と説明文を表示し、選ぶ前に違いが分かるようにする。②比較画面に A/B 入れ替えと
相手フォーメーション切替を設け、一覧に戻らず次の比較へ回遊できるようにする。
③サッカー用語をアプリ内で引ける用語集画面を追加する。

## 背景

MVP リリース後のアプリ改善提案（2026-09-12）で挙がった「学習体験」観点の課題に対応する。

- **一覧カードが名前だけ**: `Formation` は `description` と `stats` を持つのに、
  `FormationCard.vue` は `name` しか表示していない。どのフォーメーションがどんな配置なのか、
  比較画面へ行くまで分からず、「選ぶ」という最初の一歩が当てずっぽうになる。
- **比較画面が行き止まり**: 相手を変えるには一覧へ戻って 2 つ選び直す必要がある。
  要件定義書 §1.4 のプライマリ KPI は「4〜6種類を 1 周確認し終える」ことであり、
  1 組ごとに一覧へ戻る現在の導線はこの周回を直接妨げている。
- **用語の説明がアプリ内に無い**: NFR-02 は「専門用語を使う場合は用語集または文中で説明を
  添える」と定めるが、`matchups.ts` の優位ポイント文には「ウイングバック」「ピン留め」
  「数的優位」等が説明なしで登場し、用語集は `docs/` にしか無い。開発者向けドキュメントで
  あり、アプリ利用者からは参照できない。

## 実装対象の機能

### 1. 一覧カードのフォーメーションプレビュー

- フォーメーションカードに、そのフォーメーション単体の選手配置を示すミニピッチ図を表示する
- カードに `description`（フォーメーションの説明文）を表示する
- ミニピッチ図は自陣を下・攻撃方向を上とする縦向きで描画し、`positions` の座標をそのまま使う
- 利用者は一覧画面の時点で「4-3-3 は前が 3 枚で両翼が高い」等の違いを視覚的に把握できる

### 2. 比較画面の回遊性（A/B 入れ替え・相手切替）

- 比較画面に「⇄ 入れ替え」ボタンを置き、押すと A と B を入れ替えた比較
  （`/compare/:formationBId/:formationAId`）を表示する
- 比較画面に A 側・B 側それぞれのフォーメーション切替セレクトを置き、選ぶとその組み合わせの
  比較へ遷移する
- 入れ替え・切替による遷移は履歴を積まない（`router.replace`）。ブラウザバックおよび
  「← 戻る」で一覧画面へ戻れる状態を保つ
- 相手側に既に選ばれているフォーメーションは、セレクト上で選択できない
  （同一フォーメーション同士の比較は `functional-overview.md`「エラーハンドリング」の
  マッチアップ未検出になるため、UI 側で発生させない）

### 3. アプリ内サッカー用語集

- 新ルート `/glossary` に用語集画面を追加し、サッカー用語を「用語・読み方・平易な説明」の
  形式で一覧表示する
- 収録対象は、アプリが画面に表示する文章（`matchups.ts` の優位ポイント・`radarAxes.ts` の
  軸説明・`formations.ts` の説明文）に実際に登場するサッカー用語とする
- 一覧画面と比較画面の双方から用語集へ遷移できる導線を置く
- 用語データは静的データとして `src/data/` に持ち、追加時にコード変更が不要な構造にする

## 受け入れ条件

### 1. 一覧カードのフォーメーションプレビュー

- [ ] 一覧画面の各カードに、フォーメーション名・ミニピッチ図・説明文が表示される
- [ ] ミニピッチ図には、そのフォーメーションの全 11 ポジションが描画される
- [ ] ミニピッチ図は攻撃方向が上（`y` が大きいポジションほど上）に描画される
- [ ] カードのクリック・キーボード操作による選択挙動が、従来どおり動作する
      （トグル選択・2 件選択で比較画面へ遷移）

### 2. 比較画面の回遊性

- [ ] 比較画面に「⇄ 入れ替え」ボタンがあり、押すと A/B が入れ替わった比較画面が表示される
- [ ] 入れ替え後、優位ポイントの左右・レーダーチャートの系列・総合判定が入れ替え後の
      A/B に対応した内容になる
- [ ] A 側・B 側のセレクトでフォーメーションを変更すると、その組み合わせの比較画面へ遷移する
- [ ] 各セレクトでは、相手側に選択済みのフォーメーションが選択不可（`disabled`）になっている
- [ ] 入れ替え・切替の遷移は `router.replace` で行われ、履歴が積み上がらない

### 3. アプリ内サッカー用語集

- [ ] `/glossary` にアクセスすると、用語データの全件が一覧表示される
- [ ] 各用語に、平易な日本語の説明が添えられている
- [ ] 一覧画面から用語集へ遷移できる
- [ ] 比較画面から用語集へ遷移できる
- [ ] 用語集画面から一覧画面へ戻れる
- [ ] `matchups.ts` の優位ポイント文に登場する主要なサッカー用語が収録されている

## 成功指標

- 定量的な KPI は設けない（個人開発・要件定義書 §1.4 の方針を踏襲）
- 定性的には次を達成とする:
  - 一覧画面だけでフォーメーション同士の配置の違いが分かる
  - 比較画面から一覧へ戻らずに次の組み合わせへ移れる
  - 優位ポイント文中の用語の意味をアプリ内で確認できる

## スコープ外

以下はこのフェーズでは実装しません:

- 相性マトリクス表（別セッションで `.steering/20260912-formation-matchup-matrix/` として
  並行実装中）
- 解説文中の用語へのインラインツールチップ・自動リンク付与（用語集ページ単体に留める。
  本文の自動走査は誤マッチの調整コストが高いため、別フェーズで検討する）
- 用語集の検索・カテゴリ絞り込み機能（収録数が数十件規模のため、一覧表示で足りる）
- 比較画面の「← 戻る」ボタンの遷移方式の変更（`router.push` のまま。改善提案 B-⑥ として
  別途扱う）
- 一覧カードでの `stats`（レーダー値）の表示

## 未決事項

- ミニピッチ図をカード内でどの程度の大きさにするかは、実装時に画面を見ながら決める
- 用語集の収録語数は、`matchups.ts` 等の実文言を走査して確定する
