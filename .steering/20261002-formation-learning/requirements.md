# 要求内容

## 概要

フォーメーションごとの学習画面で、選手とボールの動き、優位が生まれる条件、相手の対応後の判断を学べるようにする。

## 背景

比較画面に共通教材を置くと、個々の陣形の特徴を学ぶ入口として分かりにくい。シャビの指示に従い、陣形そのものの学習と陣形間の比較をそれぞれの画面に配置する。

## 実装対象の機能

### 1. 陣形別の学習画面
- 一覧に比較選択と独立した「この陣形を学ぶ」のリンクを置く。
- 全8陣形に専用画面を用意し、全体配置と教材中の役割の対応を示す。
- 同じ画面から他の陣形へ切り替えられる。

### 2. 陣形の特徴を説明する場面再生
- 各陣形に異なる1教材、各5段階の解説を用意する。
- 4-4-2は2トップ、4-3-3はウイングとSB、4-2-3-1はダブルボランチとトップ下、3-5-2は中央からWB、5-3-2は奪った後の2トップ、4-1-4-1はアンカー、3-4-3はウイングとWB、4-1-2-1-2は中央の菱形とSBを扱う。
- 有利な場面だけでなく、相手の対応によって選び直す場面も扱う。
- 比較画面から教材を撤去する。

## 受け入れ条件

### 学習画面
- [x] 全8陣形の学習リンクがあり、押しても比較選択に追加されない。
- [x] 不明な陣形IDではエラー案内と一覧へのリンクを表示する。
- [x] 陣形変更で旧教材の再生状態を破棄し、新教材を初期状態で表示する。

### 教材
- [x] 全8教材の選手の役割が実際の陣形のポジションに対応する。
- [x] 各教材の文章と動きが異なり、5つの解説を順番に学べる。
- [x] 再生・一時停止・前後の解説・最初から・動きを減らす設定が機能する。
- [x] 比較画面に場面再生が表示されない。
- [x] モバイルで横にはみ出さず、操作対象は44px以上を確保する。

## 成功指標

- 8/8陣形で一覧から学習を開始できる。
- 勝敗の断定ではなく、動きと判断条件を説明できる。

## スコープ外

- 自動試合シミュレーション、複数教材、学習履歴・採点。
