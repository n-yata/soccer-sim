# 要求内容

## 概要

陣形学習画面に「この陣形をボードで試す」導線を置き、学んでいる陣形を青チームに選んだ状態で
自由配置ボードを開けるようにする。読んで終わりにせず、すぐに自分で動かして確かめられる学習の流れを作る。

## 背景

- 陣形学習画面（FR-20）では陣形ごとの動きと判断を再生で学べるが、学んだ配置を自分で動かして試すには、
  主ナビから自由配置ボード（FR-21）を開き、陣形セレクトで同じ陣形を選び直す必要がある。
- 2つの画面が独立しているため、「学ぶ → 試す」の流れが途切れている（2026-10-04 の改善案で、最初に挙げた案）。

## 実装対象の機能

### 1. 陣形学習画面の「ボードで試す」導線
- 陣形学習画面の2か所に、学習中の陣形でボードを開くリンク（文言: 「この陣形をボードで試す →」）を置く。
  - 概要欄: 基本配置のミニピッチの下
  - 戦術再生（教材）セクションの後
- リンク先は `/board?blue={陣形ID}`。教材が見つからない（不明な陣形 ID）場合は導線を出さない。

### 2. 自由配置ボードの初期陣形指定
- ボード画面はクエリ `blue` で青チームの初期陣形を受け取る。受け取りはルート定義の `props` で行い、
  ボード画面は vue-router に直接依存しない。
- 指定された陣形 ID が実在すれば、青チームをその陣形で開く。その陣形の端末保存済み配置（`A:{陣形ID}`）が
  あれば復元する（既存の保存・復元の仕組みをそのまま使う）。
- クエリが無い・空・実在しない陣形 ID の場合は、従来どおり既定（青 `formations[0]`）で開く。エラーは出さない。
- 赤チームとボールは従来どおり（赤は既定 `formations[1]`、ボールは保存位置または中央）。
- 開いた後に陣形セレクトで変更した場合の挙動は従来どおり（URL は更新しない）。
- 主ナビの「自由配置ボード」はクエリなしの `/board` のまま。

### 3. ドキュメントの同時更新（repository-structure.md の同時更新ルール）
- `functional-overview.md`: 画面一覧（ボードの初期陣形指定）・画面遷移図（陣形学習 → ボード）・関連 FR の記述
- `wireframes.drawio`: `wireframe-formation-learning` に2か所の導線を追加
- `screen-design.md`: 画面7（導線の項目・イベント）・画面8（クエリによる初期陣形）
- `component-design.md`: FormationLearningPage・FreeLayoutBoardPage・ルート定義の記述
- 画面詳細設計書 `screen-07` / `screen-08` と単体テスト仕様書 `test-screen-07` / `test-screen-08` に追加分を反映

## 受け入れ条件

### 1. 学習画面の導線
- [ ] 陣形学習画面（全8陣形）の概要欄と教材の後の2か所に「この陣形をボードで試す →」があり、リンク先が `/board?blue={その陣形ID}` である
- [ ] 不明な陣形 ID の学習画面には導線が表示されない
- [ ] 導線をクリックすると、自由配置ボードが学習中の陣形を青チームに選んだ状態で開く（実ルーターで確認）

### 2. ボードの初期陣形
- [ ] `blue` に実在する陣形 ID を渡すと、青チームの陣形セレクトと選手配置がその陣形になる
- [ ] その陣形の保存済み配置（青）がある場合は、保存位置が復元される
- [ ] `blue` が無い・空・実在しない ID の場合は、青が既定（`formations[0]`）で開き、エラーにならない
- [ ] 赤チームとボールは `blue` の有無で変わらない
- [ ] 主ナビの「自由配置ボード」のリンク先は `/board` のまま

### 3. ドキュメント
- [ ] 上記「3. ドキュメントの同時更新」の各ファイルが更新され、`wireframeConsistency.test.ts` を含む全テストがパスする
- [ ] 単体テスト仕様書の追加ケースがテストとして実装され、完了欄が `[x]` になっている

### 共通
- [ ] `npm test` / `npm run lint` / `npm run typecheck` / `npm run build` がパスする

## 成功指標

- 陣形学習画面から1クリックで、同じ陣形を自分で動かせる状態になる（陣形の選び直しが不要）

## スコープ外

以下はこのフェーズでは実装しません:

- 教材の局面（攻撃・守備の選手、ボールの位置）をボード上に再現すること
- 赤チーム（相手）の陣形をクエリで指定すること
- ボードでの陣形変更を URL に反映すること
- ボードから学習画面へ戻る導線
