# 要求内容

## 概要

全8ページ(フォーメーション一覧・比較・マトリクス・用語集・クイズ・リーグ戦・カップ戦)を対象に、
デザインの一貫性向上とレスポンシブ対応強化を行うUI/UXアップグレード。

## 背景

現状調査の結果、以下の問題が確認された:

- 各ページが個別に`<style scoped>`を持ち、色・フォントサイズ・角丸・余白の値がページごとに
  微妙に異なる(font-sizeだけで11種類、border-radiusが5種類のバリエーション)
- 色のハードコード(`var()`を使わず直接`#hex`)がほぼ全ページ・全コンポーネントに存在
  (ComparisonPage 16箇所、MatrixPage 21箇所など)
- `@media`によるレスポンシブ対応があるのは全19ファイル中3ファイルのみ
  (ComparisonPage.vue, MatchSimulationPanel.vue, MatchupPitchDiagram.vue)。
  グリッド・flex横並び・固定pxが大半で、モバイル幅で崩れる可能性が高い
- 共通ヘッダー/グローバルナビが存在しない。`App.vue`は`<router-view/>`のみで、
  ナビゲーション導線はトップページ(FormationListPage)の独自ヘッダーにしかなく、
  他ページ(Matrix/Glossary/Quiz/League/Cup)は個別の「戻る」ボタンのみで
  他画面への横移動ができない

## 実装対象の機能

### 1. デザイントークンの拡張

- `src/styles/tokens.css`にスペーシング・フォントサイズ・角丸・影のスケールを追加し、
  既存のバラバラな値を統一する
- 既存の`--color-*`はそのまま維持(色相自体の変更は本タスクのスコープ外)

### 2. 共通グローバルナビゲーションの追加

- 全ページ共通のヘッダー/ナビゲーションコンポーネントを新設し、`App.vue`に配置
- 一覧・比較・マトリクス・用語集・クイズ・リーグ戦・カップ戦への遷移導線を
  どのページからでも到達可能にする
- モバイル幅ではハンバーガー等でナビを折りたたむ

### 3. 全ページのレスポンシブ対応

- 各ページに`@media`クエリを追加し、モバイル(〜480px)・タブレット(〜768px)幅で
  レイアウトが崩れないようにする(グリッド列数の調整、flexの縦積み化、padding縮小)
- ピッチ図(SVGコンポーネント)は`viewBox`ベースで元々可変だが、周辺レイアウトとの
  兼ね合いを個別に確認する

### 4. トンマナの統一

- ハードコードされた色をトークン変数(`var(--color-*)`)へ置換
- font-size/border-radius/box-shadowの値を新設したトークンスケールへ揃える
- 各ページ固有の「戻る」ボタン・リンク類のスタイルをコンポーネント化し重複を排除

## 受け入れ条件

### デザイントークンの拡張
- [ ] `tokens.css`にスペーシング・フォントサイズ・角丸のスケール変数が追加されている
- [ ] 既存の`--color-*`系トークンの値は変更されていない(意図的な変更が無い限り)

### 共通グローバルナビゲーションの追加
- [ ] 全8ページのいずれからでも、他の全ページへ2クリック以内(ナビ展開含む)で遷移できる
- [ ] モバイル幅(375px想定)でナビゲーションが画面幅からはみ出さない

### 全ページのレスポンシブ対応
- [ ] 375px幅・768px幅の双方で、全8ページが横スクロールを起こさず表示できる
- [ ] グリッド/横並びレイアウトがモバイル幅で適切に縦積み・列数調整される

### トンマナの統一
- [ ] 変更対象ファイルにおいて、色のハードコード(`#hex`直書き)が
      `var(--color-*)`または新設トークンに置換されている
      (アイコン絵文字・SVGの塗り等、トークン化不要な箇所を除く)
- [ ] font-size/border-radiusの値が新設トークンスケールに揃っている

## 成功指標

- 全8ページで375px/768px/1280px幅の目視確認においてレイアウト崩れが無いこと
- 既存のVitestテスト・型チェック・ビルドが全て通ること(UI変更によるロジック破壊がないこと)

## スコープ外

- 配色(カラーパレット)自体の刷新・ブランドカラーの変更
- ダークモード対応
- 新規ページ・新規機能の追加
- アニメーション・トランジションの大幅な追加(既存のアニメーションは維持)
- SVGピッチ図の描画ロジック自体の変更(レイアウト崩れ対応のCSS調整のみ)
