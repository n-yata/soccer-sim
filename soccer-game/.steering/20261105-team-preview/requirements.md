# 要求内容

## 概要

決定前のプレビューを、**自分の駒全員の動きを、駒のモーションで**見せる形に変える。

- いま: 選んだ手で直接動く選手（プレスの1人・ドリブルの1人・スルーパスの受け手・マークの付け直し）だけを、移動先の半透明の駒と点線の曲線の矢印で見せる。
- これから: 相手が何もしないと仮定して、**手の動き（1拍目）**と、続く**詰め直し（2拍目。方式によるチーム全体のスライド・押し上げ・マークの付け直し）**の両方を、自分の駒全員分、半透明の駒が今の位置から動いて見せる。動き終えたら少し止まって元に戻り、手を選び直すか決定するまでくり返す。点線の矢印はやめる。

ルールは変えない。見せ方だけの変更。

## 背景

2026-11-05、シャビの要望（別セッション simplify-choices 経由）:
> 1人分の動きしか動き先が見えないのを、自コマ全部の動きが見えるようにすべき。→をやめて、コマが移動するモーションにも変更して

シャビの確認（2026-11-05）: 見せる範囲は「手の動き＋詰め直し」、見せ方は「動いて戻るをくり返す」。

## 実装対象の機能

### 1. 相手が何もしないときの3つの配置（ドメイン）
- 自分の手を選んだときの、ターン開始時（いま）・判定時（手の動きの後）・次のターン開始時（詰め直しの後）の配置。
- 相手が何もしないときの結果の仮定:
  - 攻撃（運ぶ先のある手）: 手が通る（前進。ボールは運ぶ先へ、保持のまま）。
  - シュート: 決まるかで置き直しが変わるので、詰め直しは見せない（1拍目だけ）。
  - 守備: ボールは動かず、相手の保持のまま（膠着と同じ）。
  - トランジション: いまのプレビューと同じく、相手を動かない手にして判定した結果（自然な結果）。
- 配置の計算は、判定と試合の進め方と同じ関数を通す（表示した動きと、相手の手の影響を除いて実際に起きる動きを食い違わせない）。

### 2. 駒のモーション（UI）
- 自分の駒のうち、3つの配置のどこかで位置が変わる駒を、半透明の駒で、いま → 判定時 → 次のターン開始時の順に動かす（駒の進み方は開示と同じイージング）。動き終えたら少し止め、元の位置へ戻してくり返す。
- 元の駒は、いまの位置に立てたまま（いまの配置も見える）。
- 点線の曲線の矢印と、移動先に立てていた半透明の駒は描かない。
- 手を選び直したら新しい手のモーションに替え、決定・手の取り消し・次の盤面で消す。
- 動く時間・止める時間は調整値として外に出す（設定ファイル）。

## 受け入れ条件
- [ ] 3つの配置が、仮定どおりに出る（攻撃・シュート・守備・トランジションでテストを固定）。
- [ ] プレビューで、3つの配置のどこかで位置が変わる自分の駒がすべて動く。動かない駒は動かない。
- [ ] モーションはくり返し、止める時間をはさんで元の位置へ戻る。選び直し・決定・取り消しで替わる・消える。
- [ ] 点線の矢印・移動先の静止した半透明の駒を描かない。
- [ ] 時間を設定ファイルで変えられ、範囲外ならデータ層が初期値に戻す。
- [ ] シャビが遊んで判定する。

## スコープ外
- 相手の駒の動きのプレビュー。
- ボールの動きのプレビュー（ボールの行き先への矢印 `show_intent` はいまどおり）。
