# 要求内容

## 概要

開示で駒が動くときの手触りを整える（視覚的な動きの強化シリーズの4つ目。2拍の開示・ボールの軌道・結果の演出の続き）。

1. **イージング**: 駒が等速ではなく、加速して減速して止まる。
2. **ずらし**: 各拍で、ボールに近い駒から順に動き出す（ボールに反応して連鎖するように見える）。
3. **弾み**: 動いている駒が小さく浮く。影は地面に残す。
4. **拍の間の小休止**: 1拍目（プレー）と2拍目（詰め直し）の間に、短い間を置く。

ルールは変えない。見せ方だけの変更。

## 背景

2026-11-05、シャビの「OK。進んで。」による。2拍の開示（`.steering/20261103-two-beat-reveal/`）で「拍の間の小休止は質感の作業で検討する」としていた。作戦ボードの分割（6867512）で、開示の進行は `BoardReveal`、駒の道筋の状態は `BoardShift` に分かれたので、ボードを太らせずに入れられる。

## 実装対象の機能
- 駒の道筋の進み方（イージング・ずらし）と高さ（弾み）を、拍の中の進み具合から決める。ボールの動き（軌道）は変えない。
- ずらしの順は、その拍の始まりのボールの位置に近い順。ずらしが 0 なら全員同時（いまと同じ並び）。
- 小休止は、拍と拍の間にだけ置く（1拍目の前・最後の拍の後には置かない）。着地（テロップ・結果の演出）は1拍目の終わりのまま（小休止を待たない）。
- ずらしの幅・弾みの高さ・小休止の長さは、調整値として外に出す（設定ファイル）。

## 受け入れ条件
- [ ] 駒は道筋の始まりと終わりで止まり、途中は等速より遅く出て速く進み、また遅くなる（テストで固定）。
- [ ] ずらしがあると、同じ拍でボールに近い駒が遠い駒より先に進む。どの駒も拍の終わりには行き先に着く。
- [ ] 動いている駒は途中で浮き、始めと終わりと、動いていない駒は浮かない。
- [ ] 拍の間に小休止があり、2拍目はその後に始まる。着地は小休止を待たない。
- [ ] 3つの値を設定ファイルで変えられ、範囲外ならデータ層が初期値に戻す。
- [ ] シャビが遊んで、手触りを判定する。

## スコープ外
- ボールの軌道・結果の演出の変更。
- 振り返り（S-07）の盤面。
