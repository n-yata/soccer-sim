# 振り返り（20261110-chibi-cut-in）

## やったこと
- カットインの選手を、写実の体から人形（素材の骨に付けた球の頭・カプセルの手足、2階調の塗りと輪郭線、大きい目・眉・口・ほっぺ）に作り替えた。
- 髪型を3つ（前髪・つんつん・モヒカン）にし、点を決める選手は前髪、キーパーはモヒカン、奪いに来る選手はつんつん。
- 脚・腕の長さは骨のまま、頭を大きくして人形らしさを出した。蹴る瞬間のカットは、大きな頭が切れないよう画角と目線を直した。
- 使わない髪の素材（形）を外した。

## うまくいったこと
- 本物の描画で試作を撮り、方向（4案）→ 派生（5案）→ 髪型（6案）→ 頭身（3案）と段階ごとに選んでもらい、作り直し無しで決まった（`visual-direction-confirm-first` の進め方が効いた）。
- 試作は既存の舞台をそのまま使い、描く直前に骨へ部品を付ける一時スクリプトで撮った。本実装を書く前に見た目が確定した。
- 脚を縮める案は、足がボールから離れる絵で問題を見せてから選んでもらった。
- 変異8つ（縦じま・長袖・グローブ・肌・髪型・房の数・骨に付けない・写実の体を消さない）はどれもテストで落ちた。

## うまくいかなかったこと
- 比較画像の Temp のパスを書いただけで「案はどこにあるの？」と言われた。画像は開いて見せる（`Start-Process`）。
- 同じ骨に同じ名前の部品を足すと、Godot が `@MeshInstance3D@3` のような名前に変え、名前で数えるテストが落ちた。`add_child(node, true)` で読める名前（Fringe2）にした。
- 変異のスクリプトをシェル経由で書き換えたら `\n` が化けた（`backslash-via-shell-gets-mangled` の再発）。Edit で直した。
- レビューで、チュートリアルで説明だけの段階をはさむとカットインの印が残り、局面の帯が2段階続けて出なくなる不具合が見つかった（トランジションの作業の取りこぼし）。段階を始めるときに忘れさせた。
- テストの追記をシェル経由で書いて、行継続の `\` がまた化けた。Edit で直した。
- 作業の途中で、別のセッションが同じ main で規則の修正を始めていた。コミット前の差分を見て気づき、ファイルと hunk を仕分けた。

## 次に気をつけること

- コミットの前に `git diff --stat` で、自分の作業に無いファイルが増えていないかを見る（並行セッション）。
