# 要求内容

## 概要

開示の1拍目（プレー）の終わりに、ターンの結果を盤面の動きで見せる。あわせて、結果のテロップを1拍目の後に出す。

| 結果 | 見せ方 |
|---|---|
| 得点 | シュートがゴールへ飛び込み、ゴールが決めた側の色で光る。2拍目でボールはキックオフの位置へ |
| シュート阻止（セーブ） | シュートが GK の位置で止まり、止めた側の色の輪が広がる |
| ロスト・奪回成功 | ボールを奪った場所に、奪った側の色の輪が広がる |
| オフサイド | 受け手の場所に旗が立つ（守備側の色） |
| 膠着 | ボールが運ぶ先へ少し進んで、元の位置へ跳ね返される |

ルールは変えない。見せ方だけの変更。

## 背景

2026-11-03、視覚的な動きの強化シリーズの3つ目（2拍の開示・手ごとのボールの軌道の続き）。シャビの「OK。進んて」による。
シャビの判断（2026-11-03）:
- 結果のテロップは**1拍目の後に出す**（ボールが着いて結果の演出が出た瞬間）。結果が分かるのは 0.6 秒遅れるが、「どうなる？」の溜めが生まれる。「次へ」はいまどおりすぐ押せる。
- 演出は、得点・セーブ、奪取・ロスト、オフサイド、膠着の4つとも入れる。

いまは得点のとき1拍目にボールが動かず（ルール上、判定後の位置はシュートしたエリア）、テロップが開示の瞬間に出るので、ボールが飛んでいる間に結果が分かってしまう。

## 実装対象の機能

### 1. 結果の演出（UI）
- 結果の種類・場所・色の側は、`RevealView` から決める（結果・判定後のボールの位置・比較エリア・ボールを持つ側の手の運ぶ先・成功した側 `MatchTexts.turn_winner`）。
- 得点: 1拍目のボールの行き先を、決めた側が攻めるゴールの口にする（強いシュート）。2拍目はゴールの口からキックオフの位置へ。
- 膠着: 1拍目のボールを、運ぶ先へ少し進めてから元の位置へ戻す。運ぶ先の無い手（保持など）では跳ね返さない。
- 輪・ゴールの光・旗は、1拍目が終わったときから出して、決めた時間で消す。時間は調整値として外に出す（設定ファイル）。
- 判定なし・奪回失敗・前進は、演出を出さない（いまどおり）。

### 2. テロップを出す時刻（UI）
- 結果のラベル・判定理由・判定の内訳・「実戦では」は、1拍目が終わったときに出す。1拍目が無い（動きが無い）ときは、いまどおりすぐ出す。
- 開示の動きが途中で止まったとき（次の盤面・重ね表示の消去）は、まだ出していなければその時点で出す（出し忘れない）。ただし次のターンへ進んだ後に、前のターンのテロップを出さない。
- 「次へ」・効果音は、いまどおり開示の瞬間から。

### 3. 変えないこと
- 1拍目・2拍目の長さ、手ごとの軌道。
- 止める経路・動かさない場面。

## 受け入れ条件
- [ ] 結果ごとに演出の種類・場所・色の側が決まる（テストで固定。利用者が攻撃・守備の両方の向き）。
- [ ] 得点のとき、1拍目のボールがゴールの口へ動き、2拍目でゴールの口からキックオフの位置へ動く。
- [ ] 膠着のとき、1拍目のボールが運ぶ先の方へ進んでから元の位置へ戻る（始めと終わりは元の位置）。
- [ ] 演出は1拍目の終わりから出て、設定した時間で消える。次の盤面・重ね表示の消去で消える。
- [ ] テロップは1拍目の終わりに出る。1拍目が無いときはすぐ出る。止められたときも出し忘れない。次のターンの後に前のテロップを出さない。
- [ ] 演出の時間を設定ファイルで変えられ、範囲外ならデータ層が初期値に戻す。
- [ ] シャビが遊んで、演出とテロップの間を判定する。

## スコープ外
- 駒の動きの質感（イージング・ずらし）。「動きの質感」の作業で扱う。
- 効果音の変更。
- 振り返り（S-07）の盤面。
