# 要求: 画面の向きを横向きだけにする

## 背景
MVP は Android のスマートフォンの縦向きだけで設計していた（`20261017-android-only`）。シャビから
「スマホの横画面専用で遊べるようにしたほうがいい。今後 PC でも遊べるようにするならそうするべき」と提案があった。

## 決定（2026-10-18 シャビ）
- MVP の画面の向きは、Android のスマートフォンの横向き（ランドスケープ）だけにする
- 作戦ボードのピッチは横に置き、利用者の攻撃方向を画面の右にする（テレビ中継と同じ向き）
- 画面の並べ方は「左にピッチ（本体）、右に操作の列」を基本にする
- 3D 演出はメインスタンドから見下ろす視点にする
- 理由: PC の画面も横長のため、横向きで作っておけば後続マイルストーンの Windows 版でレイアウトを作り直さずに済む。
  あわせて、判定理由の内訳などをピッチと並べて見せられる
- Windows 版を後続マイルストーンとする扱いは変えない
- デザイン案は横向きの4枚（試合の手の選択中・リプレイ中・判定理由、タイトル）でシャビが方向性を承認した

## 変更する文書
- `1_requirements/`: 要件定義書（§6.1 の対象プラットフォーム、§6.2 の Windows 版の行と戻す要件）、非機能要件（NFR-25）、
  機能概要（表示仕様のピッチの向き）、アーキテクチャ概要（Windows 版への移しやすさ）
- `2_basic-design/`: 画面設計（画面の向き・並べ方・各画面のレイアウト）、コンポーネント設計（`TacticsBoard` の向き）、
  ワイヤーフレーム（12画面を横向きで描き直す）
- 作業中の詳細設計（`3_detail-design/`）は、この決定に合わせて直したうえで、詳細設計の作業とあわせてコミットする
