# 要求内容

## 概要

試合の 3D のカットイン（得点・ボールを奪った/奪われた・シュートを止めた）を、仕組みごと削除する。

## 背景

シャビの要望（2026-11-27）:「ボール奪取やゴール時のカットインの削除をお願い。android で確認すると、動画は動かない」。
3つのカットインは同じ 3D の舞台（`GoalStage3D`。SubViewport に 3D の選手を写す）で動いており、セーブだけ残しても同じく動かない。
シャビの判断: 3つとも消す・設定で止めるのではなくコードと素材ごと削除する。

## 実装対象

- `GoalCutIn` と、それだけが使う 3D の舞台・選手のモデル・動きの時間割（`goal_stage_3d.gd`・`goal_player_model.gd`・
  `goal_cut_in_art.gd`・`steal_cut_in_art.gd`・`save_cut_in_art.gd`）とテスト
- 3D モデル・動きの素材（`assets/models/goal_cut_in/`。約4.6MB）と、台帳（`LICENSES.md`）の該当の節、書き出しの `include_filter` の該当
- 時間の設定値（`goal_cut_in_sec`・`transition_cut_in_sec`）と範囲の検査、テーマの `GoalCutIn` の色
- カットインのためだけにある仕組み: 盤面の「待ち」（`"wait"`・`resume_shift`）、局面の帯の `quiet`
  （カットインを出したら次の局面の帯を出さない）

## 受け入れ条件

- [ ] 得点・ロスト・セーブの開示で、3D のカットインが出ない。得点の組み直しは止まらずに続けて動く
- [ ] ボールを奪った・奪われた次のターンでも、局面の帯（2D）が出る
- [ ] カットイン以外の開示の演出（ゴールの光・奪った場所の輪・テロップ・効果音）は変わらない
- [ ] ゲームのテストがすべて通る（`tools/run-tests.sh`）
- [ ] 設計書（要件・機能概要・アーキテクチャ・画面・データ定義・用語集・ワイヤーフレーム等）からカットインの記述を外す
- [ ] ブラウザ版の書き出しが通り、試合で得点・ロストまで進めてカットインが出ないことを確認する

## スコープ外

- 局面の帯（`PhaseBanner`）・ゴールの光などの 2D の演出の見直し
- 3D の舞台に代わる新しい演出
