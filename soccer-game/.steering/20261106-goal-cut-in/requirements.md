# 要求（20261106-goal-cut-in）

## 依頼
- シャビ「得点のときにカットインを入れてほしいな。ゴールしたことをもっとちゃんと表現したい」
- シャビ「選手がゴールを決めるカットイン。ちゃんと作りこんでほしい」
- 2D の試作を見て、シャビ「2Dすぎて全然よくないね。やり直して」→ 確認で「本当の3Dで作る」

## いまの得点の見せ方
- 開示の1拍目でボールがゴールの口へ飛び、ゴールが光る（ResultEffect の GOAL）。
- 得点した側の音（goal_for / goal_against）、テロップ「● GOAL 得点」、スコアの更新。
- 2拍目で全員がキックオフの配置へ戻る。

## 要求
1. 得点のターンの開示で、シュートがゴールに入った瞬間（1拍目の着地）に、盤面と操作の列の上へカットインを出す。
2. カットインは本当の3D（Godot の3Dの舞台を SubViewport に写す）で、選手がゴールを決める様子を見せる。
   - 夜のスタジアム（芝の縞・ライン・観客席と観客・投光器）、ゴール（ポスト・バー・網目のネット）、ボール、関節で動く選手。
   - カットを割る: 助走を横から追う → 蹴る瞬間を低く寄る → 飛ぶボールを望遠で追う → ゴールの裏からネットに刺さる瞬間（ネットがふくらむ）
     → 両腕を突き上げて喜ぶ選手。
   - 映画の帯（上下の黒帯）、「GOAL!」の叩きつけ、上の帯に「得点」、下の帯に新しいスコア。
   - 素材（画像・モデル）は使わず、基本の形とシェーダーで組む。
3. 自分の得点も相手の得点も出す。違いは色と形と文で示す（NFR-20: 色だけに頼らない）。
   - 自分: 水色。ユニフォームは無地で、胸の印は丸（●）。文は「GOAL!」と「得点」。白い閃光あり。
   - 相手: オレンジ。ユニフォームは縦じまで、胸の印はひし形（◆）。文は「GOAL」と「失点」。閃光なし、揺れは小さい。
4. カットインは自動で消える。画面を押すとすぐに消える。
5. カットインの間は盤面を止める。消えてから、キックオフの配置への組み直し（2拍目）を始める。
6. カットインの時間は設定値にする（PresentationConfig.goal_cut_in_sec。既定 3.6 秒、0〜6 秒。0 ならカットインを出さない）。

## 範囲外
- 選手の名前・顔の作り込み（選手に名前のデータが無い）。
- 新しい音（いまの得点の音を使う。鳴るのは開示の始まりのまま）。
- 振り返り画面（S-07）でのカットイン。

## 仕様の変更
- 「3D の舞台は使わない」（2026-10-23。NFR・architecture-overview）を、「得点のカットインだけ3Dの舞台を使う」に改める（シャビの判断）。

## 決め方
- 確認しなかった細部（自動で消えるか、相手の得点でも出すか、時間、カットの割り方）は既定で決めた。遊んで判定してもらい、直す。
