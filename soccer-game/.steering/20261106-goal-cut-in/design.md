## 素材（`game/assets/models/goal_cut_in/`。台帳は `game/assets/LICENSES.md`「3Dモデル・動き」）
- 体と髪: Quaternius「Universal Base Characters」の Superhero_Male と Hair_SimpleParted。テクスチャは縮めた（計約 4.5MB）。
- 動き（`animations.res`）: Quaternius「Universal Animation Library」1・2 から Sprint・Idle・Jump_Start・Jump・Roll・Yes だけ。
- 蹴る動き（`kick_motion.json`）: CMU のモーションキャプチャ 11_01（ボールを蹴る）から、体の空間の手足の向き・腰と胸の
  ひねり・首の倒れ・腰の水平の動きを 60 fps で抜き出したもの。骨の向きで移すので、体の寸法の違いを問わない。

## 動かし方
- 選手: 助走は素材の Sprint → 蹴る間は記録（Idle の上から骨を向ける）→ 喜びの姿勢 → 素材の Yes。蹴る間は低いほうの足を
  地面に着け、踏み込みから振り抜きまでは軸足（左足の指の付け根）をボールの横に留める。インパクトの瞬間に足の甲が
  ボールの後ろに来るよう、体の置き場所（`CONTACT_OFFSET`）と軸足の場所（`PLANT_OFFSET`）を合わせてある。
- キーパー: Idle の上から、構え → 踏み込み → 跳ぶ姿勢（角度の姿勢）を骨の向きで作る。跳ぶまでは足を地面に着ける。
- ユニフォーム: 体の基準の姿勢（T ポーズ）での頂点の位置を UV2 に入れ、シェーダーが高さと横の位置で部位を塗り分ける
  （シャツは首元まで覆う丸首。相手は縦じま、キーパーは長袖とグローブ）。

## 座標と時間割
- メートル。ゴールラインが x = 0（ゴールは x < 0）、y が上、ゴールの幅は z の ±3.66。選手は -x へ走って右足で蹴る（右は -z）。
- 時間割（p）: 助走 0〜0.275 → 記録の蹴る動き 0.275〜0.6（インパクト 0.40）→ ボールがゴールラインを越える 0.47 →
  ネットに刺さる 0.50 →「GOAL!」0.56〜0.64 →「得点」とスコア 0.64〜0.72 → 喜び 0.74〜 → 暗転 0.92〜1.0。
- カット: 0〜0.30 助走の横 / 〜0.43 蹴る瞬間 / 〜0.48 ボールを望遠で追う / 〜0.72 ゴールの裏 / 〜1.0 喜ぶ選手。

## 盤面との順序
1. 1拍目（シュート）が着地する → テロップを出す。得点なら `GoalCutIn.play`。出せなければすぐ `resume_shift`。
2. 2拍目（キックオフへの組み直し）は `"wait"` で止めておき、カットインの `finished`（自動・押して飛ばす・止め）で再開する。
3. 「ターンを始める」・`unbind` でカットインを止める。
4. `goal_cut_in_sec` が 0 のときは `"wait"` を付けない。
