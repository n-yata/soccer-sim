# 要求（20261110-block-shot-on-ball）

## 依頼
- シャビ「ペナルティエリアまで侵入されたときにシュートコースをふさぐという選択肢が出るときと出ないときがある」

## 調べた結果
- 条件は「ボールがペナルティエリアにあり、ボールの隣（上下左右）に守備側がいて寄せが届く」（`MoveRules.defense_options`）。
  ボールと同じエリアにいる守備側は数えていなかった。
- CPU 同士 40試合（ペナルティエリアで守る攻守ターン 103回）で、出たのは 67回（65%）。出なかった 36回のうち 28回は、
  ボールのエリアに守備側がいたのに隣が空だった。8回は近くに誰もいなかった。
- シュートを読めるのはこの手だけなので、出ない場面では同数のシュートを止める読み合いが無くなる。

## 決めたこと（シャビの選択: 「ボールのエリアの選手も塞げる」）
1. ペナルティエリアで、ボールの隣かボールのエリアに守備側がいれば、シュートコースを塞ぐを選べる。
2. 隣に守備側がいれば、いままでどおり1人がボールのエリアへ寄せる（人数 +1）。いなければ、ボールのエリアの選手が
   その場で塞ぐ（誰も動かない。人数は変わらず、シュートの読みだけが効く）。
3. 判定（同数のシュートを読まれたら阻止）は変えない。
4. 手の詳細の条件の一言（`MatchTexts.target_rule`）を、隣にいないときの塞ぎ方も含めて直す。

## 範囲外
- 近くに誰もいないときに出すこと（シャビが選ばなかった案）。
