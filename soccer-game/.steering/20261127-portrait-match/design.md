# 設計書

## 土台（縦・横の切り替え）

| 部品 | 受け持つこと |
|---|---|
| `MainShell` | ウィンドウの大きさが変わったら縦（高さ ＞ 幅）か横かを決め、基準解像度（720×1280・keep_width／1280×720・keep_height）を変え、`ScreenSwitcher` に向きを伝える。セーフエリアの余白は縦では上下、横では左右 |
| `ScreenSwitcher` | 向きを覚え、表示中の画面に伝える。新しく開く画面には `enter` の前に伝える |
| `AppScreen` | `set_portrait` で向きを受け、変わったときだけ `_apply_orientation` を呼ぶ（既定は何もしない） |

- 基準解像度は `size_changed` の中では変えず、`call_deferred` で次の処理に回す（中で変えると、ブラウザ版で拡大縮小の変換が
  古い大きさのまま残り、画面が歪んだ。ブラウザ版で回して見つけた）
- 並べる箱は `BoxContainer`（`HBoxContainer` は `vertical` を変えられない。テストで見つけた）
- 組み替えるのは配置（箱の向き・最小の大きさ・伸ばし方・親）だけで、画面の状態は変えない

## 3画面の縦の配置

| 画面 | 縦の配置 |
|---|---|
| S-01 タイトル | `Layout` を上下に。`Hero` が余った高さを受け（最小 360px・中身は上下の中ほど）、カードは中身の高さで下に寄せる（小さなカードは1段 160px） |
| S-02 試合準備 | `Columns` を上下に。陣形の区画が余った高さを受け、方式の列は最小の幅を外して中身の高さ |
| S-03 試合 | 上部バーを2段（2段目 `TopSecondRow` へ保持・局面のタグ・選択の帯を `reparent`）。外周の左右 16px。`MatchBoardPanel.set_portrait` で `Columns` を上下に、操作の列の最小の幅を外して余った高さを分ける |

- 横の配置の値はシーン・定数のまま。画面は `_ready` でシーンの値を覚えて戻す（値を二重に持たない）

## 端末の設定

- `project.godot` の `window/handheld/orientation` を 4（Sensor Landscape）から 6（Sensor）に
- ブラウザ版の PWA の manifest（`progressive_web_app/orientation`）を 1（横）から 0（any）に

## テスト戦略

- `MainShell`: 縦の判定・基準解像度と合わせ方・上下の余白の計算
- `ScreenSwitcher`: 向きが表示中・後から開く画面に1回だけ伝わる
- 3画面: 720×1280 で、上下に積まれ、要素が画面に収まる。横に戻せば左右に戻る。試合画面は向きを変えても選んだ手が残る。
  タイトルは縦長の端末（720×1558）でカードが下に寄る
- ブラウザ版を 390×844 で書き出して開き、タイトル → 試合準備 → 試合を進め、開示中に横へ回して戻す
