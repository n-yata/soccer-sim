# 要求内容

## 概要

試合画面の手のボタンを行動の名前だけにし、詳しい情報は「詳細」ボタンのポップアップで見せる。手のボタンはスクロールせずに選べるようにする。

## 背景

- 2026-11-03 の手の選択の簡素化で、手のボタンを「番号と手の名前・行き先・ヒントの札」の3行にし、ボタンの下に選んだ手の説明を出した
- シャビの判断（2026-11-05）: 「選択ボタン内の情報はシンプルに行動のみで。詳細の情報は詳細ボタンを押したらポップアップがいい」「選択ボタンリストの下の解説も邪魔。リストをスクロールしないといけない。スクロール不要でボタンを選択できるようにして」

## 実装対象の機能

### 1. 手のボタンは行動の名前だけ
- ボタンの文字は番号と行動の名前だけ（例「① ショートパス」）。番号は盤面の行き先の札と対応させるために残す
- 4つまでの手を2列に並べ、スクロールせずにすべて見える

### 2. 詳細のポップアップ
- 「決定」の左に「詳細」ボタンを置く。手を選ぶまで押せない。判定理由の表示中は隠す
- 押すと、選んだ手の名前を見出しに、行き先・判断材料（ヒントが ON のとき）・手の説明をポップアップで出す。「閉じる」で閉じ、選んだ手はそのまま

### 3. ボタンの下の説明をやめる

## 受け入れ条件

- [ ] 手のボタンの文字は番号と行動の名前だけ
- [ ] 試合画面の実寸（1280×720）で、手を選んだ後もすべての手のボタンがスクロールせずに見える
- [ ] 「詳細」は手を選ぶまで押せず、押すと行き先・判断材料・説明のポップアップが開き、閉じても選んだ手は変わらない
- [ ] 判定理由の表示中は「詳細」を隠し、ポップアップも閉じる
- [ ] 全体テストが3分以内に成功する

## スコープ外

- 手の選び方・判定の規則の変更
