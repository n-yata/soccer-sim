# 振り返り: 動く骨格

実装完了日: 2026-10-18

## 何をしたか
- アプリを起動するとタイトル画面が出て、画面の切り替え・戻る操作・終了が、PC と Android の両方で動く骨格を作った。
  - `App`（オートロード）・`AppScreens`
  - 画面の親クラス `AppScreen`、画面の入れ替え `ScreenSwitcher`、メインシーン `MainShell`（戻る操作・Esc・セーフエリア）
  - タイトル画面の骨格。行き先の画面が無いカードは押せず「準備中」と出す。画面を作って `MainShell.SCREEN_SCENES` に足せば押せるようになる
  - テーマ（`screen-common.md` §3 の色、Barlow Condensed）
- テストは 101 件（9 スイート）。
- 実際の画面で確かめたこと:
  - PC: 16:9 と 20:9 で画面を撮って配置を確かめた。Esc でアプリが閉じた
  - Android エミュレーター: タイトルが出た。戻る操作で `handle_back()` が1回だけ呼ばれ、タイトルでは閉じ、`true` を返す画面では閉じなかった
- 書き出した APK の起動の確認の手順を、`repository-structure.md` に固定した（開発環境の構築からの申し送り）。

## 計画と実績の差分
- **画面の撮り方が変わった**: 使い捨てのスクリプト（`--script`）ではオートロードの `App` が読み込まれず、メインシーンを開けなかった。
  そこで Godot の動画の書き出し（`--write-movie`）を使った。書き出しは基準の 1280×720 で切り出されるので、20:9 は一時的な `override.cfg` でビューポートを広げて撮った。
- **押せないカードの文字が読めなかった**: PC の画面で見つけた。カードの中の文字は `Button` 自身の文字ではないため、選択不可の文字色が効かなかった。
  テーマの選択不可の色にそろえる処理とテストを足した。
- **仮の画面の代わりに、タイトルを一時的に変えて確かめた**: 「`true` を返すと閉じない」の確認は、仮の画面を足す代わりに、タイトルの `handle_back()` を一時的に `true` にした APK で行った。
- **エミュレーターに新しい APK が入らなかった**: 差分だけを入れる方式では、新しい APK が反映されず、古い APK のまま動いた。ログが前と同じだったことで気づき、`--no-incremental` で入れ直した。
- **状態（`BUSY`・`CONFIRMING`）を作らなかった**: 骨格の段階では `IDLE` しか起きないため、`NewMatchGate` を作る作業へ回した（設計書を実装に合わせた）。

## 学び
- **見た目は、撮って見るまで分からない**: 押せないカードの文字が読めない問題は、テストでは通っていた。テーマの色は正しく、文字の上書きの有無という「部品の作り」の問題だったため。画面を作ったら、PC で撮って見るところまでを1セットにする。
- **確認の結果が前と同じなら、変更が入ったかを先に疑う**: 仮の APK で戻る操作を確かめたとき、ログが元の APK と同じだった。インストールが反映されていなかった。テストの変異と同じく、変更が実際に入ったことを確かめてから結果を読む。
- **きっかけを見張るより、きっかけが要らない形にする**: 180° 回したときの余白は、回転を見張るより、左右を同じにして「どちら向きでも正しい」形にする方が単純で頑丈だった。

## 申し送り
- **画面を足すとき**
  - `MainShell.SCREEN_SCENES` に1行足す。
  - タイトルのカードが押せるようになったことを、テストで確かめる（いまは行き先が1つも無いため、タイトルの `enter()` のテストは区別できていない）。
  - 画面の入れ替えを遅らせて呼ぶため、押されたボタンの処理の途中でエラーが出ないことも見る。
- **サービスを作る作業**: タイトルの次の部分を足す。
  - 再開カード
  - 小さなカードの一言
  - チュートリアルの位置の切り替え
  - 「CPU 対戦」の確認の手順と、状態 `BUSY`・`CONFIRMING`
- **`ConfirmDialog` を作る作業**: Android の戻る操作はダイアログを経由しないので、`handle_back()` でダイアログを閉じる。
- **Noto Sans JP を置く作業**（サブセット）: 次の2つを直す。
  - 小さなカードの文字の折り返し。「理解度チェック」が細かく折り返される。
  - 文字幅の確認。
- **提案のうち、申し送ったもの**
  - 対応表とカードの行き先を、型付きの Dictionary にする。
  - 手で書いた `.tscn` に uid を付ける（エディタで一度保存すれば付く）。
