# 要求内容

## 概要

理解度チェック（S-09。FR-22）を作る。学習目標 LG-1〜4 ごとの場面問題を解き、正誤と解説を確かめ、正答状況を端末内に残す。

## 背景

タイトルの「理解度チェック」は「準備中」のまま。画面一覧（S-01〜S-12）で最後に残った画面で、公開前プレイテストの学習効果の
測定（要件定義書 §1.5。LG ごとに2問・計8問）にも同じ問題を使う。場面問題・戦術原則の静的データも、回答結果の保存もまだ無い。

## 実装対象の機能

- 静的データ: `principles.json`（戦術原則カタログの書き写し）・`quiz.json`（LG ごとに2問・計8問。8問ともプレイテストの測定に使う）
- 回答結果の保存: `quiz_answers.json`（`QuizAnswerStore`。破損・新しい版の扱いは戦績と同じ）
- 正答状況: `UserDataService.quiz_progress()`（問題ごとの最新の回答で数える）・`save_quiz_answer()`
- S-09（screen-09-quiz.md）: 学習目標の一覧（2×2）、問題（場面の図・場面の文・問題文・選択肢）、回答後の正誤・解説・根拠の原則
- タイトルの「理解度チェック」が押せる。カードの一言「3／8 正解」（0件なら「未回答」）
- 問題案は 2026-10-31 にシャビの了承を得た（場面と正解は会話の表のとおり）

## 受け入れ条件

- [x] LG-1〜4 のカードに、学習目標の名前と「2問中 N問正解」／「未回答」が出る
- [x] カードを押すと、その学習目標の最初の問題を、図（両チームの人数・ボール）・方式・問題文・選択肢で出す
- [x] 選択肢を選ぶまで「回答する」は押せない。回答すると正誤・正解・解説・根拠の原則名が出て、回答を保存する
- [x] 最後の問題の後は一覧へ戻り、正答状況を描き直す
- [x] 戻る操作は、問題の表示中は一覧へ（回答前は記録しない）、一覧ではタイトルへ
- [x] 保存に失敗しても表示は進む。読み込みの破損・新しい版は未回答として出し、通知する
- [x] 問題の文に書いた人数・陣形が、場面の図とゲームの基本配置と食い違わない（テストで確かめる）
- [x] 全テストが通る

## スコープ外

- 図の中で選択肢のエリアを強調すること（今は人数とボールだけ）
- LG ごとに3問目以降の問題（プレイテストに使わない問題は、データを足せば出せる）
