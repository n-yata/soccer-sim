# 振り返り: 効果音

実装完了日: 2026-10-30

## できたこと
- CC0 のフリー音源4つ（クリック・得点・失点・笛）を `game/assets/sounds/` に置き、台帳（`game/assets/LICENSES.md`「効果音」）に調達元・作者・手を加えたことを記録した。
- `SoundCues`（オートロード `Sfx`）で、すべて `SE` バスで鳴らす。設定の効果音音量がそのまま効く。
- ボタン・カードのクリック音は、木に入った `BaseButton` に自動でつなぐ。試合画面で、ハーフの1ターン目に笛、得点の開示で得点した側の音、ハーフの終わりの開示で笛。

## 計画と実績の差分
- 最初はコードで作る音で進めかけたが、シャビの指示で最初からフリー音源にした。
- 笛は CC0 の審判の笛がなかなか見つからなかった（OpenGameArt は汽笛か CC-BY の口笛）。Wikimedia Commons の API でライセンス欄を引けるファイルを見つけた。
- ゴールは CC0 の歓声が見つからず、Kenney のジングルにした。音を聞けないので、音の高さの動き（上がる＝得点、下がる＝失点）を FFT で見て選んだ。合っているかはシャビが遊んで判断する。

## 学んだこと
- 音源を探すときは、ライセンスを機械的に読める調達元（Wikimedia Commons の API の `extmetadata`、zip に同梱のライセンスの文）から当たると早い。
- 全体のテストを裏で走らせている間に別のスイートを流すと、無関係なテストが落ちる。止めた実行の Godot も残る（メモリに記録した）。
- テストでシグナルにつないだ受け手は、途中の失敗で残らないよう `after_test` で切る。
