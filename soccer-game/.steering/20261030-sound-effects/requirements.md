# 要求: 効果音

## 概要

フリー音源（CC0）の効果音を同梱し、設定の効果音音量（`SE` バス）で鳴らす。

## 背景

設定（S-12）で効果音音量を変えられるが、音の素材が1つも無く、何も聞こえない（2026-10-30 シャビの報告）。
音源はコードで作らず、最初からフリー音源を使う（2026-10-30 シャビ決定）。

## 実装対象の機能

鳴らす場面（2026-10-30 シャビ選択）:

| 場面 | 音 |
|---|---|
| ボタン・カードを押す（全画面） | クリック音 |
| 自分の得点 | 上がるジングル |
| 相手の得点 | 下がるジングル |
| 笛: 前半・後半のキックオフ、前半・試合の終わり | 審判の笛 |

- 音はすべて `SE` バスで鳴らす（設定の効果音音量・0 でミュートがそのまま効く）。
- 素材の調達元・ライセンスは `game/assets/LICENSES.md` に記録する。

## 受け入れ条件

1. 4つの音のファイルが読み込め、どれも `SE` バスで鳴る。
2. どの画面のボタンを押しても、クリック音を鳴らす（押せないボタンが押されないのは Godot の Button の動き）。
3. 試合で自分が得点したら得点の音、相手が得点したら失点の音を鳴らす。得点の無いターンでは鳴らさない。
4. 前半・後半の最初のターンで笛を鳴らす。前半の終わり・試合の終わりの開示で笛を鳴らす。それ以外のターンでは鳴らさない。
5. 素材はすべて CC0 で、台帳に調達元・作者・手を加えたことがある。

## 成功指標

- シャビが遊んで、音が場面に合っているか（合っていなければ同じ名前のファイルを差し替える）。

## スコープ外

- BGM（素材も再生も無いまま）。
- チュートリアルでの得点・笛の音（ボタンのクリック音は鳴る）。
- 得点後の再開のキックオフの笛。
