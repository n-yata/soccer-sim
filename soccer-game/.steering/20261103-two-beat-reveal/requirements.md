# 要求内容

## 概要

試合画面（S-03）の開示で、駒とボールの動きを**2拍**に分ける。

1. **1拍目（プレー）**: 判定前の配置から**判定時の配置**へ。ボールは判定前の位置から判定後の位置へ。
2. **2拍目（詰め直し）**: 判定時の配置から**次のターン開始時の配置**へ。

ルール（どの選手がどこへ動くか）は変えない。見せ方だけの変更。

## 背景

2026-11-03、シャビから次の依頼があった。
> だいぶゲームとしては成り立ってきた。あとは、動きをもっと強化していきたい。
> 視覚的な動きを強化していきたい。

強化の方向として、次の4つを選んだ（シャビ、全部）。1つずつ入れて、その都度シャビが遊んで判定する。

1. **2拍の順番付け（この作業）**
2. 手ごとのボールの軌道（別作業）
3. 結果の演出（別作業）
4. 動きの質感（別作業）

いまは、判定前から次のターン開始時へ全員とボールを同時に 0.6 秒で動かしている（`.steering/20261022-team-shift-animation/`・`.steering/20261023-ball-shift-and-board-split/`）。
手で動いた選手と、方式で詰め直した選手が同時に動くので、**何が起点で全体が動いたのか分かりにくい**。
2拍目を分けておくと、2〜4 の作業で1拍目（プレー）だけに演出を乗せられる。

## 実装対象の機能

### 1. 開示を2拍で動かす（UI）

- 1拍目: `RevealView` の判定前の選手（`*_players_before`）→ 判定時の選手（`*_players_at_judgement`）。ボールは `ball_before` → `ball_after`。
- 2拍目: 判定時の選手 → `BoardSnapshot` の選手（次のターン開始時）。ボールは `ball_after` → `BoardSnapshot.ball_area`（得点後のキックオフなどで違うときだけ動く）。
- 動きが1つも無い拍は飛ばす（待ち時間を作らない）。
- 各拍の中では、いまどおり全員を同時に動かす。
- ある拍で動かない選手は、その拍の始まりの位置に描く（1拍目に、2拍目だけで動く選手が次のターンの位置へ飛ばない）。
- 拍の長さは調整値として外に出す（設定ファイル）。1拍目・2拍目それぞれ。拍の間の小休止は入れない（質感の作業で検討する）。

### 2. 変えないこと

- 矢印・比較エリアの札・判定理由のテロップは、いまどおり開示の瞬間に出す（出すタイミングは「結果の演出」の作業で見直す）。
- 止める経路（次の盤面・重ね表示の消去・時間の経過）と、動かさない場面（方式の選び直し・ハーフタイム後・試合の最初）は、いまどおり。
- 「次へ」の扱いは、いまどおり。

## 受け入れ条件

- [ ] 1拍目で、判定前と判定時で位置が違う選手だけが動き、2拍目で、判定時と次のターン開始時で位置が違う選手だけが動く（テストで固定する）。
- [ ] 1拍目の途中で、2拍目だけで動く選手が判定時の位置（= 1拍目の始まりと同じ位置）に描かれる。
- [ ] ボールが1拍目で `ball_before` → `ball_after`、2拍目で `ball_after` → 次のターンの位置へ動く。同じなら動かない。
- [ ] 動きが無い拍は飛ばされ、全体の時間がその拍の分短くなる。
- [ ] 2つの拍の長さを設定ファイルで変えられ、範囲外ならデータ層が初期値に戻す。
- [ ] シャビが遊んで、2拍に分けた見え方を判定する。

## スコープ外

- 手ごとのボールの軌道・結果の演出・動きの質感（イージング・ずらし・影）。それぞれ別作業。
- ルールの変更。
- 振り返り（S-07）の盤面の動き。
