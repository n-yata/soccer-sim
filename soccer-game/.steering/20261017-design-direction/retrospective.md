# 振り返り: ビジュアルの方向性（スタジアム中継風）の反映

## 何をしたか
- デザイン案（試合画面3枚・タイトル。リポジトリ外）で決めた方向性を、正本の表示仕様・画面設計・ワイヤーフレームに反映した
  - ピッチは実際のピッチとして描き、人数は駒（● 自分・◆ 相手）、優劣は15エリアの角の記号で示す（FR-16）
  - チームの色を水色・オレンジに変えた
  - 開示は中継のリプレイ風の 3D 演出と、解説テロップ風の判定理由
  - タイトルはカードの並び
- フォント（Noto Sans JP・Barlow Condensed）の同梱と、サブセット・ライセンスの扱いを記録した

## コミット前レビュー（review-pre-commit）の結果
- 第1回: Critical 0 / High 0 / Medium 5 / Low 4 / 改善提案 2。すべて対応した（再レビューなし）。レビューは利用上限で一度止まり、再開して完了した

## 学び
- 最初のデザイン案（5×3の箱に数字）は「サッカーに見えない」と言われた。部分的な手直し（駒を足す）では足りず、盤面を実際のピッチとして作り直して初めて受け入れられた。手直しで済まないと感じたら、早めに作り直す
- 見た目を変えると、要件（FR-16 の「全エリアの優劣の表示」）を満たさなくなることがある。デザイン案を正本に反映する前に、表示に関わる FR・NFR と突き合わせる
- 記号の流用（▲ を「CPU」と「優位」の両方に使う）は、色を除いたときの判別（NFR-20）で問題になる。記号は1つの意味にだけ使う
