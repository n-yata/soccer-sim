### Medium
1. **[運用] 正本からまだ追跡されていないファイルを参照している**: functional-overview.md の表示仕様（カラーコーディング）が、未追跡の `docs/specs/3_detail-design/screen/screen-common.md` を参照している。この4ファイルだけをコミットするとコミット時点で参照先が無く、NFR-21（コントラスト）の確認先が辿れない → 参照先を同じコミットに含めるか、パスは詳細設計のコミット時に足す
2. **[バグ] チームを示す記号が「丸・ひし形」と「■・▲」の2通りになり、▲ が優劣の記号とぶつかる**: wireframes.drawio の S-03 の陣形・方式の帯（「■ 自分…／▲ CPU…」）と注記（■／▲）。表示仕様では駒が丸・ひし形。角の ▲（優位）と帯の ▲（CPU）がグレースケールで紛らわしく、NFR-20 の確認で誤読の原因になる → 帯の印を ●・◆ に揃える
3. **[バグ] 「選べるエリアの札」の出し方と数字の形式が、正本と画面設計で揃っていない**: 正本は人数の数字（`2−1`）を選べるエリアの札で示すと読める。画面設計のヒントの行は、ヒントが ON のときに `+1`・`±0 GK外`、選んだエリアだけ `+1  1対0`。比較エリアの札は `1 対 0`。ヒントが OFF のときに札で人数を示すのか、数字の形式が `2−1` か `1対0` かで実装が分かれる → 正本に、札を出す条件・人数の書き方・人数差がヒントの一部であること（FR-19）を明記し、画面設計とワイヤーフレームを揃える
4. **[バグ] S-01 の説明と画面項目定義が食い違っている**: 説明はチュートリアルを未完了なら「CPU 対戦の直前」、完了後は「小さなカードの並びの最後」とするが、項目定義は「未完了なら先頭」のまま。小さなカードの一言（正答状況・通算成績）に取得元が無い。種別も「ボタン」のまま → 備考を直し、一言の取得元（`UserDataService`）を足す
5. **[運用] フォントのサブセットに使う文字の決め方が書かれていない**: 解説・チュートリアル・単純化カタログの文言はデータファイルから出る。サブセットの元にする文字の範囲と作り直す契機が無く、文言を足したときに字が欠けても気づけない → UI とデータファイルの全文言から生成し、文言が変わるたびに作り直し、欠けた文字を検出する確認を設けると書く

### Low
1. **[運用] コミットされる文書に、ロールプレイ上の呼び名と他の人が辿れない作業場所が残っている**（screen-design.md「ビジュアルの方向性」の「シャビと決めた」「claude.ai の Artifact で作った」。機密ではなく、実際のリンクも無い） → 「プロダクトオーナー」などにし、Artifact への言及は消すか「リポジトリ外」とする
2. **[バグ] 局面の表示が文書と図で揃っていない**: 本文は「上部バーの下のタグ（`ATTACK` など）」、ワイヤーフレームの注記は「上部バー: …局面（攻撃／…）」のまま。図の表示と画面項目定義は日本語 → 位置と表記を揃える
3. **[バグ] ミニピッチの人数の書き方が表示仕様で決まっていない**: wireframes.drawio の S-05・S-09 は `2−1` 形式の数字（今回は変更していないページ）。正本は人数を駒で示すとしたので、ミニピッチも駒で描くのか数字のままでよいのかが無い → 表示仕様にミニピッチの書き方を足す
4. **[バグ] ヒントの札の例が画面設計と図で違う**: ワイヤーフレーム S-03 ①の選んだエリアの札が `+1` だけで、画面設計の例 `+1  1対0` と違う

### 改善提案
- フォントの OFL 1.1 は、配布物にライセンス本文と著作権表示を含めることを求める。台帳への記録に加え、APK に `OFL.txt` を同梱するか、アプリ内にライセンス表示を設けることを依存関係管理に一言足すとよい
- サブセット化は OFL の「改変版」にあたる。予約フォント名（RFN）があると名前を変える必要があるので、台帳への記録の際に RFN の有無も確認するとよい

### 対応
- **Medium 1**: 対応した。表示仕様から未追跡ファイルのパスを外し、「詳細設計の画面共通の決めごとで行う」とした
- **Medium 2**: 対応した。陣形・方式の帯のチームの印を ●・◆ にし、表示仕様にも「チームを文字で示すときも ●・◆」と書いた。ワイヤーフレームの帯と注記も直した
- **Medium 3**: 対応した。表示仕様に「ヒントの札」の行を足した（ヒントが ON のときだけ出す、例 `+1`・`±0 GK外`、選んだエリアは `+1  1対0`、OFF のときは駒と優劣記号）。人数の数字は `自分 対 相手`（例 `1対0`）に統一した。画面設計のヒントの行は表示仕様を参照する形にした

- **Low 1**: 対応した。「プロダクトオーナーと決めた」「リポジトリ外」にした
- **Low 2**: 対応した。局面は上部バーの下のタグで、英字に日本語の局面名を添える形に統一した（画面項目定義とワイヤーフレームの注記）
- **Low 3**: 対応した。表示仕様に「ミニピッチは `自分−相手`（例 `1−0`）の数字と優劣記号」を書いた
- **Low 4**: 対応した。ワイヤーフレーム S-03 ①の選んだエリアの札を `+1 1対0` にした
- **改善提案**: 2件とも対応した（ライセンス本文と著作権表示の同梱・アプリ内のライセンス表示、予約フォント名の確認）
