# 設計方針

- 正本は `docs/specs/1_requirements/`。基本設計では ID・データ型・アルゴリズムを再定義せず、参照する
- 基本設計の中で生じた「ぶれてはいけない決定」は `1_requirements/` に昇格させる（AGENTS.md「決定は 1_requirements に昇格させる」）
- ワイヤーフレームは `repository-structure.md`「ワイヤーフレームの運用」に従い、`wireframes.drawio` の1ファイル・画面ごとに1ページ（ページ名 `wireframe-sNN-...`）
- drawio MCP が接続できない場合は .drawio の XML を直接書く
