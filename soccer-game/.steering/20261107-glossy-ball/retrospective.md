# 振り返り（20261107-glossy-ball）

## 実装の内容
- サッカーボールを、駒と同じ光沢の 3D で描いた（`PieceSprites` の BALL_KEY。描く処理と材質を駒と共通にした）。
- 模様は本物のボールと同じ切頂二十面体の12の五角形。正面に1枚が来る向き。
- 3D が無いときは、今までの平面のボール。

## 計画との差分
- 球の分割を 48×96 から 96×192 にした。拡大すると五角形の縁が段になったため。五角形の頂点を覚えて使い回し、作成は約 0.1 秒。

## 学んだこと
- **テストの範囲は、勘ではなく計算で決める。** 黒の割合を「〜0.28」と書いたら、正しい実装（約 0.283）で落ちた。切頂二十面体の五角形の大きさから計算し直した。
- 駒で作った描き方（1回だけ 3D で描いて絵にする）を共通にしておくと、ボールは材質も光も自然にそろった。
