# 設計（20261107-glossy-ball）

- `PieceSprites` に、ボールの絵（`BALL_KEY`）を足す。駒と同じ `_render`（正射影・同じ光・同じ光沢の材質 `_glossy_material`）で描く。
  - 絵は 128×128、ボールの半径は 56px で真ん中に写る。
  - 球は 96×192 に分けたメッシュ。法線は球の向きそのもの。48×96 では、拡大すると五角形の縁が段になった。
  - 模様は切頂二十面体: 五角形の中心は正二十面体の12の頂点、頂点は中心から隣の中心へ 1/3 進んだ向き。球面の多角形として内外を判定する（`on_pentagon`）。
  - 最初の五角形が、ボールの中心からカメラへの向き（21° 見下ろす）に来るよう回す（`ball_pattern_rotation`）。
  - 白はテーマの `ball`、黒は `bg`（平面のボール・胸の印と同じ）。
  - 五角形の頂点は一度求めたら覚えて使い回す。メッシュを作るのに約 0.1 秒（試合画面を開いたときに1回）。
- `BoardPainter._draw_lifted_ball`: `PieceSprites.ball_texture` が絵を返せば `ball_rect` で縮めて置く。無ければ今の平面のボール。影と浮き方は変えない。
- 駒の絵とボールの絵を描く処理を `_render(key, size, unit_px, target, node, label)` にまとめた。
