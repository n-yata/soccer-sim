# 要求内容

## 概要

ゲームの表現範囲（S-10。FR-23）を作る。ゲームが単純化している戦術要素と、実戦での扱いを一覧にする。

## 背景

タイトルの「表現範囲」は「準備中」のまま。チュートリアルの作業で単純化カタログ（`simplifications.json`）と一覧の部品
（`SimplificationList`）ができたので、それを使ってタイトルからいつでも見られるようにする。

## 実装対象の機能

- S-10（screen-10-scope.md）: ヘッダー（「← 戻る」と「ゲームの表現範囲」）、説明文、単純化のカード（ID 順・2列・縦にスクロール）
- カードの見出しは「SIM-01 縦方向のライン調整」、「実戦では」は caution の色（S-08 の最後の一覧も同じ表示になる）
- 戻る操作でタイトルへ
- タイトルの「表現範囲」のカードが押せる。「表現範囲」「設定」のカードに一言を出す（「実戦との違い」「音量・ヒント」）

## 受け入れ条件

- [ ] 単純化カタログの全項目が ID 順に、名前・ゲームでの扱い・実戦では の3行で出る
- [ ] 「実戦では」が caution の色で出る
- [ ] 戻る操作でタイトルへ
- [ ] タイトルの「表現範囲」が押せる
- [ ] 全テストが通る

## スコープ外

- 「実戦では」の吹き出し（解説・振り返り・ヒント。単純化の作業）
