# 初期要求

## 解決したい課題

サッカーのフォーメーションを勉強できるアプリが欲しい。
例: 4-2-3-1と4-4-2だったらどちらが有利か、といった比較・学習ができること。

「有利/不利」の判定・学習体験は、以下の4種類を組み合わせたい（優先順位はMVPの範囲で検討中）。

1. 定性的な戦術知識ベースの解説（例: 「4-2-3-1はサイドの厚みで4-4-2の中盤を上回りやすいが、
   2トップの数的優位を許しやすい」といった戦術理論に基づくテキスト・図解）
2. 簡易シミュレーション/数値計算（各フォーメーションにパラメータを与えて、疑似的に勝敗・
   支配率などを計算するロジック）
3. 対戦相手との相性表（フォーメーションA vs Bの組み合わせごとに有利不利をマトリクスで見せる）
4. ユーザー自身が選手を配置して視覚的に確認する（ピッチ図でポジション・カバーエリアを可視化し、
   噛み合わせのズレを目で見て学べるようにする）

## ターゲットユーザー

サッカー戦術を独学したい一般ファン。専門的な戦術用語を噛み砕いて学べることを重視する。
**開発者本人（サッカーの知識はほぼ無い）が最初のユーザー**であり、初心者でも理解できる
噛み砕いた説明であることが重要。

## 主要機能

1. フォーメーション一覧画面（複数のフォーメーションから選べる）
2. 2つのフォーメーションを選んで、ピッチ図を並べて比較表示する画面
   （選手配置を視覚的に見比べられる）
3. 選んだ組み合わせに対する戦術解説文の表示（強み・弱みの噛み合わせ）

「解決したい課題」に挙げた4種類の学習体験のうち、MVPでは 1(定性的な戦術解説) と
4(視覚的な配置確認) を組み合わせる。2(簡易シミュレーション)・3(相性表) は
MVP後の拡張候補とする。

## MVP の範囲

### 作るもの

- 上記「主要機能」の3画面
- 代表的な4〜6種類のフォーメーション（例: 4-4-2, 4-3-3, 4-2-3-1, 3-5-2 等。
  最初の動機となった 4-2-3-1 vs 4-4-2 の組み合わせは必ず含める）
- 各フォーメーションのピッチ図（選手配置座標）
- フォーメーションの組み合わせごとの戦術解説文
  - コンテンツは Claude が一般的な戦術理論の知識をもとに作成し、シャビがレビューする
  - サッカー戦術には流派・解釈の幅があるため、広く合意されている基本的な知識を
    中心に書く（特定の指導者・書籍の独自理論には依らない）
- データ構造はフォーメーション・解説文を後から追加しやすい設計にする
  （4〜6種類から段階的に拡張する前提）

### 作らないもの（後回し）

- 簡易シミュレーション/数値計算による勝敗・支配率の算出
- フォーメーション相性のマトリクス表
- ユーザーが自由に選手を配置してカスタマイズする機能
- アニメーション・動きのある演出（MVPは静的な比較体験。「つまらなければ」次段階で検討する）
- バックエンド・DB・ユーザーアカウント機能

## 制約・前提

- プラットフォーム: Webアプリ（ブラウザで動作。インストール不要）
- 技術スタック: Vue + TypeScript。ピッチ図は SVG または Canvas 描画
- 構成: フロントエンドのみで完結（バックエンド・DBは無し。フォーメーションデータや
  解説文は静的な JSON/TS ファイルとして持つ）
- 納期: 特になし（趣味・学習目的のプロジェクト。急ぎの締切は無い）
- 公開範囲: 未定（特に指定なし）
- 開発環境: Windows（このリポジトリ `soccer-sim`）

## 未解決の論点

- 戦術解説コンテンツの正確性は Claude の一般知識に依存するため、事実誤認や偏りが
  ないか、シャビによるレビュー体制をどう回すか（要件定義以降で検討）
- MVP後、②簡易シミュレーション・③相性表のどちらを先に拡張するかは未定
- 一般公開するかどうかは未定（個人利用に留めるか判断はこの先で良い）
