## 備考

- テストケース1-4（`countAllPairs`）は、FR-13の進捗表示の分母がフォーメーション数から
  正しく算出されることの担保である。
- テストケース10・11（確認済み/未確認の`aria-label`）は、チェック印が`aria-hidden`である
  ため、支援技術での区別を`aria-label`側で担保する必要があることに対応する。
- テストケース17（マッチアップ未定義の表示）は、`matchups.test.ts`の全ペア網羅テスト
  （`test-screen-02-comparison.md`参照）により通常運用では発生しない前提だが、
  UIコンポーネント側の防御的な表示分岐として独立に検証する。
