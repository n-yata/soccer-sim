## テスト対象

| `freeLayoutCoordinates`（`components/freeLayoutCoordinates.ts`） | ユニットテスト（Vitest）。外部依存なしの純粋関数 |
| `applyOverrides` / `savePositionOverride` / `clearFormationOverride`（`data/freeLayoutStorage.ts`） | ユニットテスト（Vitest。jsdom の `localStorage`、例外系は `Storage.prototype` をスパイ） |

| `FreeLayoutBoardPage` | ユニットテスト（Vitest + Vue Test Utils。実データ・jsdom の `localStorage`） |

## 前提データ（全テストケース共通）

`data/formations.ts` の実データ（8陣形）を使う。各テストの前に `localStorage` を空にする。
ボードの初期状態は青 `formations[0]`（4-4-2）、赤 `formations[1]`（4-3-3）、ボールは中央（`{ x: 50, y: 50 }`）。
