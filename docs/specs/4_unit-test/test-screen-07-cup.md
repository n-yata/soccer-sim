## 備考

- `vue-router`の`useRouter`はモック化する。
- テストケース9（`runCupSimulation`のPK戦の呼び出し順非依存）は必須とする。
  `simulateMatch`が保証している「呼び出し順に依存しない」という不変条件を、PK戦の判定でも
  同じ正準順の考え方で担保していることの検証であり、2026-09-20のコミット前レビューで
  一度この不変条件が崩れているのを発見・修正した経緯がある。
- テストケース15（`CupPage`の勝者表示の色以外の手段）は必須とする。2026-09-26の
  アクセシビリティ監査で「勝者強調が色のみに依存していた」指摘を受けて修正した箇所であり、
  かつ当初のテストは勝者・敗者どちらにクラスが付いても通ってしまう恒真テストだったため
  （2026-09-26のコミット前レビューで発見）、勝者/敗者を`winnerId`から一意に判別し
  両方の状態を検証する形にしている。
