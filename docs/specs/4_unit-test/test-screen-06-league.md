## 備考

- `vue-router`の`useRouter`はモック化する。
- テストケース9（`runLeagueSimulation`の同着順位の採番）は、`component-design.md`
  「leagueSimulation」で明記された同着順位方式（1, 2, 2, 4, ...）の唯一の担保であり必須とする。
- LeaguePage関連のテストケース（11-16）は、詳細設計・実装が先行し単体テスト仕様書への反映
  および実テストの作成が漏れていた項目（2026-09-26発見）。本書への記載を機に、実際の
  `LeaguePage.test.ts`作成を別途のタスクとして起票すること。
