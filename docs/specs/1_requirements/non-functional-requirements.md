## このドキュメントの役割

非機能要件を IPA 非機能要求グレードの分類で体系化し、NFR-ID を採番する。
各要件に**目標・基準と測定方法**を必ず付す。性能目標には実測値・計測日・実行環境も記録する。

## 書くべきこと

- 性能・拡張性 / 信頼性・データ整合性 / セキュリティ / 運用・保守性・テスト容易性 /
  ユーザビリティ（該当するもののみ。限定・対象外は理由を明示）
- 各要件の目標・基準・測定方法（NFR-ID採番）
- 実測結果（性能目標。未計測なら「未計測」と明記する）
- 対象外・限定対応の観点とその理由

## 書かないこと

- テストの書き方・カバレッジ方針の型（→ `<kit>/reference/rules/testing.md`）
- コードレビュー観点の型（→ `<kit>/reference/rules/code-review.md`）
- 機能要件（FR）（→ `requirements-definition.md`）
